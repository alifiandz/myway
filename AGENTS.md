# MyWay repository

This is the active, complete public MyWay application repository: https://github.com/alifiandz/myway.

When the user requests GitHub MyWay updates, work in this repository. The former name was `myway-showcase`. The older private repository is preserved separately as `alifiandz/myway-source`; do not publish its private contents.

Keep documentation accurate about implemented features and future plans. Preserve original development history. Never commit credentials, local environment files, user data, or generated build artifacts. Website deployment is separate from repository updates.
