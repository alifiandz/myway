# MyWay development history

The application was developed through 185 source commits from August 19 to October 31, 2026. The original public full-source import was a single snapshot; it did not represent the start or extent of development.

The real development lineage is now preserved alongside the existing GitHub history. Original source dates, author labels, and parent relationships were retained. Contact emails were anonymized. Only audited public paths were retained, and production identifiers were sanitized, so restored commit hashes differ from the private originals.

Generic “Update Site source” messages have descriptive titles derived from their actual changed files. The original message and source commit are recorded in each commit body. No development dates, code changes, or activity were fabricated.

The final public-release preparation commits separate the real administrator configuration, branding, documentation, and verification changes made for publication. They do not claim those changes happened earlier. The previous import snapshot is also preserved on an archive branch.
