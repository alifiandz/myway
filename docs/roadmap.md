# MyWay: current scope and development direction

## Included in the current source

The v182 source contains Indonesia and international university discovery, programme and comparison views, Dream/Target/Alternative pathways, readiness and preparation tracking, tasks and habits, a month calendar, focus sessions, local document handling, account planning synchronization, cloud-document integration code, administrator review tools, and feedback APIs.

These are code capabilities. Availability of connected features depends on the deployment’s authentication, database, storage, and identity configuration. Repository tests use fixtures/mocks where appropriate; they are not proof that all live integrations have been audited.

## Next development priorities

### 1. Deeper, more trustworthy university information

Expand structured programme and curriculum coverage, improve source provenance, and make missing or stale intake information clearer. Tuition comparisons should explicitly represent currency, fee period, and applicant category. Official admission sources remain the authority.

### 2. Clearer personal preparation

Improve next-action guidance and explain what is ready, missing, or still unverified. Keep fit, preparation readiness, and admission likelihood conceptually separate. Refine comparison and pathway language using student feedback.

### 3. Reliable continuity and recovery

Strengthen existing planning and document synchronization rather than treating them as a future invention. Expand cross-device integration tests, interruption recovery, backup/restore guidance, and account-boundary validation.

### 4. Repeatable production validation

Rehearse migration replay on a fresh environment, validate database/storage policies, review administrator boundaries, and exercise restore procedures. Continue accessibility, mobile, and performance checks. Keep deployment separate from source publication until these checks are reviewed.

## How to read this roadmap

These are priorities informed by the source and existing engineering notes. They are not release dates, promises of admissions outcomes, or claims that future improvements are already complete. No paid plan, AI adviser, or application-submission integration is being announced by this source release.
